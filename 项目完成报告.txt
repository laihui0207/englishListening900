================================================================================
                           快速开始（3步）
================================================================================

步骤1：打开网站
   → 双击 english-listening-practice.html
   → 网站会在浏览器中自动打开

步骤2：导入句子
   → 打开 final_sentences.txt
   → 复制所有内容（Ctrl+A, Ctrl+C）
   → 在网站底部找到"📝 导入句子"区域
   → 粘贴并点击"导入句子"按钮

步骤3：开始练习
   → 点击"▶️ 播放"听句子
   → 点击"👁️ 显示原文"查看答案
   → 点击"🔄 重播"再听一遍
   → 使用"⬅️ 上一句"和"下一句 ➡️"导航

================================================================================
                           推荐学习方法
================================================================================

🎯 方法1：三遍学习法
   第一遍：不看原文，纯听力练习
   第二遍：看着原文，边听边学
   第三遍：再次不看，检验效果

🎯 方法2：跟读练习
   听一句 → 暂停 → 跟读3遍 → 对比发音

🎯 方法3：每日计划
   初级：每天 10-20 句，重复3遍
   中级：每天 30-50 句，重复2遍
   高级：每天 50-100 句，快速过一遍

================================================================================
                           故障排除
================================================================================

问题：没有声音
解决：
  1. 检查设备音量
  2. 检查网站音量设置
  3. 在"发音"菜单中选择其他语音
  4. 尝试其他浏览器

问题：没有英语语音选项
解决：
  Windows: 设置 → 语音 → 添加语音
  Mac: 系统偏好设置 → 辅助功能 → 语音内容

问题：发音不自然
解决：
  选择带有"Google"或"Microsoft"的语音选项
