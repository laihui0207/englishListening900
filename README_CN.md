# 🎧 英语900句听力练习网站

完整的英语听力学习系统，支持高质量音频播放、中英文对照、自定义句子、TTS回退和Docker一键部署。

---

## ✨ 核心特性

- 🎵 **900个高质量音频** - Edge-TTS生成，接近真人发音
- 📖 **中英文对照显示** - 430句完整翻译
- 💾 **自动保存进度** - 学习进度自动记录
- 🔄 **智能TTS回退** - 无音频时自动使用浏览器TTS
- ➕ **自定义句子追加** - 导入新句子并持久化保存
- ⚡ **跳转功能** - 快速跳转到任意句子
- 🎚️ **播放控制** - 速度调节（0.5x-1.5x）、音量控制
- ⌨️ **快捷键支持** - 空格、R、S、←、→
- 📱 **响应式设计** - 支持手机/平板/电脑
- 🐳 **Docker部署** - 一键容器化部署

---

## 🚀 快速开始

### 方法1：本地运行（最简单）

1. **双击启动**
   ```
   启动服务器.bat
   ```

2. **浏览器自动打开**
   ```
   http://localhost:8888
   ```

### 方法2：Docker部署（推荐生产环境）

```bash
# 启动容器
docker-compose up -d

# 访问网站
http://localhost:8888
```

或使用部署脚本：
```bash
docker-deploy.bat      # Windows
./docker-deploy.sh     # Linux/Mac
```

## ⌨️ 快捷键

- `空格` - 播放/暂停
- `R` - 重播当前句子
- `S` - 显示/隐藏原文
- `←` - 上一句（自动播放）
- `→` - 下一句（自动播放）
- `回车` - 跳转（在输入框中）

## 📖 使用教程

### 1. 基础播放
1. 打开网站
2. 点击"播放"按钮
3. 听音频，尝试理解
4. 点击"显示原文"查看中英文

### 2. 跳转功能
1. 在"跳转到指定句子"区域输入句子编号
2. 点击"跳转"或按回车
3. 自动跳转并播放

### 3. 导入自定义句子
1. 滚动到"导入自定义句子"区域
2. 输入英文句子（每行一句）
3. 点击"导入句子（追加）"
4. 新句子追加到第901句开始
5. 自动使用TTS播放

### 4. 学习进度
- 自动保存功能默认开启
- 下次打开自动恢复位置
- 可以关闭开关重新开始

## 🔧 开发说明

### 技术栈
- **前端**: HTML5 + CSS3 + JavaScript (ES6)
- **音频**: Edge-TTS + Web Audio API + Web Speech API
- **数据**: JSON
- **存储**: LocalStorage
- **部署**: Docker + Nginx

### 脚本工具
- `scripts/batch_generate_audio.py` - 批量生成音频
- `scripts/extract_pdf.py` - PDF内容提取
- `scripts/deep_clean_translations.py` - 清理翻译数据
