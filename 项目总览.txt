================================================================================
                         开发流程
================================================================================

数据准备
   1. PDF提取 → extract_pdf.py
   2. 英文提取 → extract_english_only.py
   3. 翻译提取 → extract_translations_v2.py
   4. 数据清理 → deep_clean_translations.py
   5. 最终输出 → sentences_data.json

音频生成
   1. 测试单个 → generate_audio.py
   2. 批量生成 → batch_generate_audio.py
   3. 输出目录 → audio/
   4. 文件命名 → sentence_001.mp3 ~ sentence_900.mp3

网站开发
   1. HTML结构 → index.html
   2. 样式设计 → CSS in HTML
   3. 功能实现 → app_audio.js
   4. 数据加载 → sentences_data.json

Docker部署
   1. Dockerfile → 镜像定义
   2. docker-compose.yml → 编排配置
   3. nginx.conf → 服务器优化
   4. 构建测试 → docker-compose up -d

文档编写
   1. 功能文档 → docs/
   2. 部署文档 → docs/
   3. 测试指南 → docs/
   4. README → 根目录

================================================================================
                         部署方式对比
================================================================================

本地Python服务器
   ✓ 优点：简单快速、无需安装
   ✓ 缺点：仅本机访问
   ✓ 适用：个人学习
   ✓ 命令：启动服务器.bat

Docker本地部署
   ✓ 优点：隔离环境、易于管理
   ✓ 缺点：需要安装Docker
   ✓ 适用：开发测试
   ✓ 命令：docker-compose up -d

Docker云部署
   ✓ 优点：公网访问、稳定可靠
   ✓ 缺点：需要服务器
   ✓ 适用：在线服务
   ✓ 命令：docker-compose up -d + 域名配置

================================================================================
                         常见问题
================================================================================

Q1: 如何快速开始？
A1: 双击"启动服务器.bat"，浏览器自动打开网站

Q2: 音频无法播放？
A2: 检查audio文件夹是否存在，确认有900个MP3文件

Q3: 如何使用Docker部署？
A3: 运行 docker-compose up -d，访问 http://localhost:8888

Q4: 导入的句子没有声音？
A4: 导入的句子自动使用浏览器TTS，确保浏览器支持Web Speech API

Q5: 如何清除学习进度？
A5: 关闭"自动保存学习进度"开关

Q6: 自定义句子如何保存？
A6: 自动保存到浏览器localStorage，下次打开自动加载

Q7: 如何修改端口？
A7: 编辑docker-compose.yml中的ports配置

Q8: 文档在哪里？
A8: docs/目录包含所有文档，推荐先看README_CN.md
