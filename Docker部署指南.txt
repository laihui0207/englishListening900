# 基本运行
docker run -d -p 8080:80 --name english-listening english-listening:v3.0

# 指定其他端口（例如8888）
docker run -d -p 8888:80 --name english-listening english-listening:v3.0

# 运行并查看日志
docker run -d -p 8080:80 --name english-listening english-listening:v3.0 && docker logs -f english-listening

# 运行时挂载本地文件（用于开发）
docker run -d -p 8080:80 \
  -v $(pwd)/index.html:/usr/share/nginx/html/index.html:ro \
  -v $(pwd)/app_audio.js:/usr/share/nginx/html/app_audio.js:ro \
  --name english-listening english-listening:v3.0

================================================================================
                         端口配置
================================================================================

默认端口映射：8080:80
   - 主机端口：8080
   - 容器端口：80
   - 访问地址：http://localhost:8080

修改端口：
   编辑 docker-compose.yml 文件

   ports:
     - "9999:80"  # 改为9999端口

   然后重新启动：
   docker-compose down
   docker-compose up -d

🌐 使用域名访问

1. 配置反向代理（使用nginx或traefik）
2. 设置SSL证书（使用Let's Encrypt）
3. 配置域名解析

示例nginx反向代理配置：

server {
    listen 80;
    server_name english.example.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

🔒 HTTPS配置

使用Let's Encrypt获取免费SSL证书：

1. 安装certbot
   apt-get install certbot python3-certbot-nginx

2. 获取证书
   certbot --nginx -d english.example.com

3. 自动续期
   certbot renew --dry-run

================================================================================
                         故障排除
================================================================================

❌ 问题1：端口被占用

错误信息：
bind: address already in use

解决方法：
1. 查看占用端口的进程
   netstat -ano | findstr :8080  (Windows)
   lsof -i :8080                 (Linux/Mac)

2. 修改docker-compose.yml中的端口
   ports:
     - "8081:80"  # 改用其他端口

❌ 问题2：容器无法启动

解决方法：
1. 查看日志
   docker logs english-listening

2. 检查nginx配置
   docker exec english-listening nginx -t

3. 重新构建
   docker-compose up -d --build

❌ 问题3：音频文件无法加载

解决方法：
1. 检查audio文件夹是否正确复制
   docker exec english-listening ls -la /usr/share/nginx/html/audio | head -20

2. 检查文件权限
   docker exec english-listening ls -l /usr/share/nginx/html/

3. 查看nginx日志
   docker exec english-listening cat /var/log/nginx/error.log

❌ 问题4：镜像太大

解决方法：
1. 使用.dockerignore排除不必要的文件
2. 使用alpine基础镜像（已使用）
3. 压缩音频文件（如果可能）

❌ 问题5：无法访问网站

解决方法：
1. 检查容器是否运行
   docker ps

2. 检查端口映射
   docker port english-listening

3. 测试nginx
   docker exec english-listening wget -O- http://localhost

4. 检查防火墙
   # Windows
   netsh advfirewall firewall add rule name="Docker Port 8080" dir=in action=allow protocol=TCP localport=8080
