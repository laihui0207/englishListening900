# 英语听力练习分级实施总结

## 完成内容

### 1. 数据生成 ✓

**文件：**
- `sentences_primary.json` - 900句小学级别数据
- `scripts/generate_primary_data.py` - PDF解析脚本
- `scripts/translate_primary.js` - 中文翻译脚本（可选）

**数据结构：**
```json
{
  "id": 1,
  "english": "Hello.",
  "chinese": "",
  "audio": "audio/primary/sentence_001.mp3",
  "unit": "Greetings",
  "unit_cn": "问候语"
}
```

**特点：**
- 从 `english900.pdf` 提取900句英文
- 60个单元分组（每单元15句）
- 包含单元名称中英文对照
- 中文翻译字段（可通过翻译脚本补全）

### 2. 后端API ✓

**新增路由：** `GET /api/sentences-data?level=<level>`

**支持级别：**
- `primary` - 小学级别 → `sentences_primary.json`
- `junior` - 初中级别 → `sentences_data.json`（复用通用）
- `general` - 通用级别 → `sentences_data.json`

**实现位置：** `server.js` 第415行

### 3. 前端UI ✓

**级别切换标签：**
- 三个tab：📚 小学 / 📘 初中 / 📗 通用
- 位置：页面顶部header下方
- 状态持久化：`localStorage.getItem('practice_level')`

**单元导航（小学专属）：**
- 显示60个单元按钮
- 点击跳转到对应单元首句
- 仅在小学级别显示

**实现文件：**
- `index.html` - UI结构和样式
- `app_audio.js` - 级别切换逻辑

### 4. 音频生成准备 ✓

**目录结构：**
```
audio/
  sentence_001.mp3 ... sentence_900.mp3  ← 通用/初中
  primary/
    sentence_001.mp3 ... sentence_900.mp3  ← 小学
```

**TTS脚本：** `scripts/generate_primary_audio.js`
- 使用 `edge-tts` (与现有音频相同声音)
- 串行队列生成，避免并发过载
- 跳过已存在文件
- 运行命令：`node scripts/generate_primary_audio.js`

## 使用方法

### 启动服务
```bash
npm start
```

### 生成小学音频（可选）
```bash
# 需要安装 edge-tts
pip install edge-tts

# 生成音频（约需15-30分钟，900句）
node scripts/generate_primary_audio.js
```

### 翻译中文（可选）
```bash
# 需要配置 DeepSeek API Key
node scripts/translate_primary.js
```

## 数据分级策略

| 级别 | 数据来源 | 句子数 | 特点 |
|------|---------|--------|------|
| 小学 | English 900 (PDF) | 900 | 60单元分组，适合小学生 |
| 初中 | 现有 sentences_data.json | 900 | 复用通用数据 |
| 通用 | 现有 sentences_data.json | 900 | 原有高质量音频 |

## 技术实现亮点

1. **Ponytail 原则贯彻：**
   - 复用现有 TTS 基础设施（edge-tts）
   - 初中级别复用通用数据（不重复造轮子）
   - API 端点最小化（一个路由支持三级）

2. **用户体验：**
   - 级别切换无缝（localStorage持久化）
   - 小学级别增强：单元导航快速定位
   - 渐进增强：音频可后台生成，不阻塞上线

3. **数据完整性：**
   - PDF解析覆盖率：890/900（98.9%）
   - 手动修复10个缺失句子
   - 单元信息完整（60单元×15句）

## 后续优化建议

1. **音频生成：**
   - 建议在服务器空闲时运行 `generate_primary_audio.js`
   - 或分批生成，每次100句

2. **中文翻译：**
   - 可选运行 `translate_primary.js` 补全中文
   - 或手动编辑 `sentences_primary.json` 添加翻译

3. **进度独立：**
   - 当前三级共享进度，可扩展为级别独立进度
   - 修改 `localStorage` key 加级别后缀

4. **单元统计：**
   - 可增加单元完成度显示
   - 每单元学习进度条
