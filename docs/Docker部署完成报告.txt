================================================================================
                         快速部署步骤
================================================================================

🚀 方法1：使用Docker Compose（最简单）

第1步：确保Docker已安装
   docker --version
   docker-compose --version

第2步：构建并启动
   cd D:\workspace\demo
   docker-compose up -d

第3步：访问网站
   http://localhost:8080

第4步：查看状态
   docker-compose ps

🚀 方法2：使用部署脚本（推荐）

Windows用户：
   1. 双击 docker-deploy.bat
   2. 选择 [6] 重新构建并启动
   3. 选择 [8] 测试访问

Linux/Mac用户：
   chmod +x docker-deploy.sh
   ./docker-deploy.sh

🚀 方法3：手动Docker命令

构建镜像：
   docker build -t english-listening:v3.0 .

运行容器：
   docker run -d -p 8080:80 --name english-listening english-listening:v3.0

访问网站：
   http://localhost:8080
