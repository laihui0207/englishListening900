================================================================================
                         使用方法
================================================================================

1. 刷新浏览器页面
   按 F5 或 Ctrl+R

2. 开始练习
   - 先听音频（不看原文）
   - 测试自己是否听懂

3. 查看答案
   - 点击"👁️ 显示原文"按钮
   - 同时看到英文和中文
   - 对照理解句子含义

4. 继续练习
   - 点击"下一句"自动播放
   - 重复步骤2-3

================================================================================
                         推荐学习流程
================================================================================

🎯 方法1：听力理解训练

   步骤1：听音频（不看原文）
          尝试理解句子意思

   步骤2：显示中英文对照
          确认自己是否理解正确

   步骤3：再听一遍（看着原文）
          加深印象，学习发音

   步骤4：第三遍（不看原文）
          检验学习效果

🎯 方法2：翻译练习

   步骤1：显示原文
          先看中文翻译

   步骤2：尝试翻译
          在心里说出英文

   步骤3：对照英文原文
          检查自己的翻译

   步骤4：听音频
          学习正确发音

🎯 方法3：跟读模仿

   步骤1：显示中英文对照
          理解句子含义

   步骤2：听音频
          注意发音和语调

   步骤3：暂停跟读
          模仿刚才的发音

   步骤4：对比练习
          再听一遍，对比差异

📦 数据结构

   每个句子包含：

     "id": 1,                              // 句子编号
     "english": "Hello, how are you?",     // 英文原文

   英文：
   - 字体大小：1.3em
   - 颜色：深色 (#333)
   - 位置：上方

   中文：
   - 字体大小：1.1em
   - 颜色：灰色 (#666)
   - 位置：下方
   - 分隔：2px边框线

🔧 自动适配

   - 有翻译：显示英文+中文
   - 无翻译：只显示英文
   - 响应式：自动适配手机/平板/电脑

================================================================================
                         常见问题
================================================================================

Q1：为什么有些句子没有中文翻译？
A1：原始PDF文件中后470句没有提供翻译，我们保留了英文和音频，
    方便高级学习者直接练习听力。

Q2：可以添加自己的翻译吗？
A2：目前不支持在界面上添加，但可以编辑 sentences_data.json 文件
    手动添加中文翻译。

Q3：中文翻译准确吗？
A3：翻译来自原始教材，准确度较高。部分翻译可能比较直译，
    实际使用时要根据语境理解。

Q4：能否只显示英文，不显示中文？
A4：目前点击"显示原文"会同时显示中英文。如果只想看英文，
    可以忽略下方的中文部分。

Q5：手机上显示效果如何？
A5：完全支持手机浏览，中英文会自动换行，保持良好的阅读体验。
