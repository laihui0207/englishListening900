================================================================================
                    1. 跳转到指定句子
================================================================================

📍 功能说明
   可以直接跳转到任意句子，无需逐个点击"下一句"

🎯 使用方法
   1. 在"跳转到指定句子"区域找到输入框
   2. 输入句子编号（1-900）
   3. 点击"跳转"按钮或按回车键
   4. 系统会自动跳转并播放该句子

💡 使用场景
   - 快速跳到上次学习的位置
   - 重点练习某个范围的句子
   - 跳过已熟悉的内容
   - 随机抽查练习

⌨️ 快捷操作
   在输入框中输入数字后，直接按回车键即可跳转

================================================================================
                    2. 自动保存学习进度
================================================================================

💾 功能说明
   自动记录你当前学习到第几句，下次打开时自动恢复

🎯 工作原理
   - 开启时：每次切换句子都会自动保存进度
   - 关闭时：不保存进度，每次从第1句开始
   - 进度保存在浏览器本地（localStorage）
   - 不占用服务器资源，完全本地存储

🔧 如何使用

   开启自动保存（默认）：
   ✓ 切换开关到"开启"状态（绿色）
   ✓ 每次切换句子自动保存
   ✓ 下次打开自动恢复到上次位置
   ✓ 会显示恢复时间提示

   关闭自动保存：
   ✓ 切换开关到"关闭"状态（灰色）
   ✓ 清除已保存的进度
   ✓ 每次从第1句开始
   ✓ 适合多人共用或重新开始

💡 使用建议

   建议开启（默认）：
   - 个人使用
   - 长期学习计划
   - 希望记录进度

   建议关闭：
   - 多人共用一台电脑
   - 随机练习
   - 每次都想从头开始

================================================================================
                         技术细节
================================================================================

🔐 数据存储
   - 位置：浏览器 localStorage
   - 内容：当前句子编号 + 时间戳
   - 大小：< 1 KB
   - 安全：仅本地存储，不上传

📊 存储的信息
   {
     "currentIndex": 149,           // 当前句子索引（0-899）
     "timestamp": "2024-09-07T19:30:00.000Z"  // 保存时间
   }

🔄 自动保存时机
   - 点击"下一句"按钮
   - 点击"上一句"按钮
   - 使用跳转功能
   - 使用键盘快捷键（← →）

⚠️ 注意事项
   - 清除浏览器数据会删除进度
   - 不同浏览器的进度独立
   - 隐私模式/无痕模式不保存进度

================================================================================
                         快捷键说明
================================================================================

原有快捷键（不变）：
   空格  - 播放/暂停
   R     - 重播
   S     - 显示/隐藏原文
   ←     - 上一句（自动播放 + 保存进度）
   →     - 下一句（自动播放 + 保存进度）

新增快捷操作：
   回车  - 在跳转输入框中按回车直接跳转

================================================================================
                         常见问题
================================================================================

Q1：跳转后会自动播放吗？
A1：会的！跳转后会立即播放该句子的音频

Q2：关闭自动保存会删除已保存的进度吗？
A2：会的，关闭时会清除已保存的进度

Q3：可以跳转到任意句子吗？
A3：可以，输入1-900之间的任何数字

Q4：进度保存在哪里？
A4：保存在浏览器本地存储（localStorage），不上传到服务器

Q5：换台电脑能恢复进度吗？
A5：不能，进度仅保存在当前浏览器

Q6：怎么重新从第1句开始？
A6：方法1 - 关闭自动保存
    方法2 - 在跳转框输入"1"并跳转

Q7：进度会占用多少空间？
A7：非常小，少于1KB，几乎可以忽略不计

📚 学习计划推荐

第一周：基础入门（句子1-100）
   - 开启自动保存
   - 每天学习20句
   - 第二天从上次位置继续

第二周：进阶练习（句子101-200）
   - 保持自动保存开启
   - 使用跳转功能复习前一天内容
   - 例如：今天学到150句，跳回130句复习

第三周：巩固强化
   - 使用跳转功能随机抽查
   - 关闭自动保存，每次随机练习
   - 或开启自动保存，系统性学习新内容

🎯 进阶技巧

技巧1：分段练习
   - 跳转到某个起点（如句子200）
   - 连续练习30句
   - 第二天跳回这30句复习

技巧2：重点突破
   - 遇到难句记下编号
   - 使用跳转功能反复练习
   - 例如：句子456、句子523

技巧3：测试模式
   - 关闭自动保存
   - 使用跳转功能随机抽查
   - 测试对各部分的掌握程度
